# 验证服务设置区精简设计

## 目标

把当前同时展示密钥、浏览器地址、状态和说明的“过盾设置”改成普通用户能快速理解的“验证服务”卡片，同时保留本地高级配置能力，不改变任何支付或验证接口。

## 方案比较

- 维持全部展开：操作最直接，但信息拥挤、专业术语暴露过多。
- 独立设置弹窗：主页面最干净，但增加弹窗层级，测试状态与配置状态容易脱节。
- 卡片内折叠高级配置：默认状态清晰，需要时原地展开，改动范围小。

采用第三种方案。

## 界面结构

- 标题使用“验证服务”，不再使用“过盾设置”。
- 默认折叠，只展示一个状态点、简短状态文案和“配置”按钮。
- 展开后展示：
  - “备用验证密钥”输入框，对应现有 CapSolver API Key。
  - “连接现有浏览器”输入框，对应现有 CDP 地址。
  - “测试连接”和“保存设置”两个动作。
- `BROWSER_WS_ENDPOINT`、配置文件路径和调用机制等实现细节移入一行低对比度高级提示，不占据主视觉。
- 测试成功、测试失败和保存成功使用卡片内状态条反馈，不使用额外弹窗。

## 视觉与动效

- 延续天空蓝白背景，但展开面板使用略深的淡蓝底，避免大片纯白。
- 状态点区分“已配置”“本地模式”“连接失败”，文字同时表达状态，不只依赖颜色。
- 展开/收起使用短距离淡入和高度过渡；遵守 `prefers-reduced-motion`。
- 在窄屏下按钮自动换行，输入框保持整行宽度。

## 验收

- 默认状态下不显示密钥和浏览器地址输入框。
- 设置按钮正确维护 `aria-expanded`，折叠内容可通过键盘操作。
- 保存和测试继续调用现有接口，功能行为不变。
- 密钥仍只显示脱敏值。
- UI 静态测试覆盖标题、折叠状态、可访问性属性和已删除的冗长说明。
