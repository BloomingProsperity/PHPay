# 资源库严格导入与可见选择设计

## 目标

将账号、卡、地址从“文件夹 + 模糊导入控件”整理为可理解的资源层：文件单独导入、严格解析、真实统计、脱敏查看，并让单笔任务明确显示当前选中的资源。

手动填写卡和地址保留为备用折叠区。支付、外部验证、代理、浏览器规避逻辑，以及批量支付执行逻辑均不在本次范围内。

## 已确认的交互

每个资源类型在右侧资源库中只有两个主入口：

- `导入文件`：打开 B 型导入抽屉。
- `查看/选择`：展示脱敏列表，并可选中一项填入当前单笔任务。

导入抽屉包含：选择文件、已选文件清单及移除操作、一个“开始导入”按钮、进度/结果区域。旧的常驻文件选择器、粘贴框和第二个“批量导入”按钮移除。

单笔任务区显式显示当前已选账号、卡、地址；选择资源后不能只偷偷改变折叠表单。卡和地址手动填写仍可在备用折叠区编辑。

当单笔任务没有已选地址时，在用户点击单笔操作前从内置地址生成器生成一条随机地址，填入备用折叠区并显示为“本次临时地址”。临时地址只存在于当前页面任务状态，默认不写入地址库；用户可通过明确的“保存到地址库”操作持久化它。已导入且已选中的地址始终优先于临时地址。

## 严格导入规则

文件彼此独立解析，绝不拼接多个文件内容。

| 资源 | 接受的扩展名 | 解析规则 |
| --- | --- | --- |
| 账号 | `.json`、`.txt` | JSON 对象或数组必须含 `accessToken` 或 `sessionToken`；TXT 一个文件只能有一条非空凭据记录。 |
| 卡 | `.json`、`.csv`、`.txt` | JSON 对象/数组使用 `number`、`exp`、`cvc`、`name`；CSV 表头允许同义字段映射；TXT 每行固定为 `number|MM/YY|CVC|name`，姓名可省略。 |
| 地址 | `.json`、`.csv`、`.txt` | JSON 对象/数组使用 `line1`、`city`、`state`、`zip`、`country`；CSV 必须映射地址、城市、州、邮编、国家；TXT 固定为 `line1|city|state|zip|country`。 |

所有记录先标准化为内部字段，再验证。格式不明、字段缺失、卡日期不合法、地址结构不完整的记录不入库。每个文件产生新增、重复跳过、错误三类结果；错误仅含文件名、行号和错误类别，不返回原始敏感内容。

CSV 同义表头只在预定义映射中接受：卡使用 `number/card_number/cardNumber`、`exp/expiry` 或月年字段、`cvc/cvv`、`name/holder/cardholder`；地址使用 `line1/address1/street`、`city`、`state/province/region`、`zip/postal/postal_code`、`country/country_code`。无表头、未映射字段或分隔符猜测均不接受。

本次采用“重复跳过，不覆盖旧资源”的保守规则。重复检测使用标准化数据的稳定标识；导入返回的新增数必须等于实际新增文件数。

## 资源表示与数据暴露

资源在磁盘上继续使用本地 JSON 存储，但每条记录拥有稳定 ID 和最小元信息（导入时间、来源文件、来源行）。读取列表只返回脱敏显示字段和 ID：

- 账号：显示标签（邮箱或本地编号），不返回原始凭据。
- 卡：仅显示尾号与持卡人显示名，不返回完整号码或安全码。
- 地址：显示规范化的地址摘要。

导入失败、运行日志与列表接口均不得回显原始凭据、完整支付卡信息或安全码。

## 与任务区的连接

前端维护当前单笔任务的 `selectedAccountId`、`selectedCardId`、`selectedAddressId`，并显示对应的脱敏标签。选中资源后才读取本地完整内容以填充当前单笔任务；手动填写时显示为“手动输入”。

本次不改变批量支付或批量生成链接的执行策略，也不把资源选择接入批量支付。页面会准确标明批量功能仍使用既有库范围，避免暗示当前单笔选择会影响批量执行。

## 导入状态与失败处理

前端提交后显示文件级状态：等待、解析中、完成、失败。后端对每个文件返回独立结果，前端据此更新资源数量和列表。网络或服务器失败时，保留已选文件和可读错误，允许重试；只有导入成功的文件从清单移除。

## 验证

- 为三类解析器补充覆盖合法、非法、重复、多文件、CSV 表头、错误行的测试。
- 为导入接口验证：不拼接文件、不写入非法记录、重复不覆盖、返回统计等于磁盘实际变化。
- 为列表接口验证：不返回原始账号凭据、完整卡号或安全码。
- 为前端验证：B 抽屉文件清单、开始导入、成功/失败状态、数量刷新、选择状态和手动备用区。
- 不运行任何会触发外部支付或批量支付的端到端测试。
