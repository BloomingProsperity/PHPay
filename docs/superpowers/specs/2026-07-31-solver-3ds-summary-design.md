# 验证配置与 3DS 摘要设计

## 目标

- 验证配置中的清除按钮必须稳定居中在输入框右侧，不挤压输入框，也不贴住下边框。
- 3DS 主卡不直接展示账号邮箱或账号明细，只展示“待验证”和“最近完成”的数量。
- 点击非零数量行时，在现有通用弹窗中展示对应账号列表；点击账号后继续复用现有 3DS 详情弹窗。

## 范围

- 只修改 `public/reference-ui.css` 和 `public/index.html` 的展示与点击事件。
- 保留现有 `/api/payment-tasks` 与 `/api/payment-tasks/:id/three-ds-detail` 数据接口。
- 不修改支付、轮询、3DS 状态判定与资源锁逻辑。

## 交互

- 两个数量行始终可见，数量为零时禁用查看操作。
- 数量大于零时整行可点击，弹窗列出全部对应账号。
- 账号列表中的每一行仍可打开原有支付链接、卡片使用统计和账号等级详情。
